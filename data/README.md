# Data

This directory holds sample data used for local development and testing of
the QA engine.

## sample_campaigns.csv

A placeholder CSV defining the expected campaign data schema
(`campaign_name`, `channel`, `url`, `utm_source`, `utm_medium`,
`utm_campaign`). It currently contains no rows. Representative sample
records will be added once the rule-based QA engine (Phase 2) is
implemented, so that sample data reflects the actual validation rules.
